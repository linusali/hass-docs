A community project to document how one villa in our villa community replaced the
proprietary *TIS Control* panel with the free, open-source *Home Assistant*
platform - so neighbours with the same wiring can do the same, learn from what
worked, and support each other.

== Why this exists

Our villa community has several villas that share the same underlying hardware
layout, originally controlled by a proprietary panel system called *TIS Control*.
One villa successfully replaced the "brain" of that system with *Home Assistant*,
using:

* *Zigbee* for lighting, switches, and similar low-voltage smart-home devices
* A small, community-written *custom integration*
  (https://github.com/linusali/hass-tis-vrf-ac[hass-tis-vrf-ac]) to keep controlling
  the villa's own *VRF air-conditioning* system (each villa has its own dedicated
  VRF controller and unit) that TIS Control used to manage
* Standard, free, open-source Home Assistant add-ons for everything else

This repository documents that setup so other residents with similar hardware can
replicate it, understand the trade-offs, and support each other as a community -
nobody is obligated to do this, and nobody should feel pressure to move faster than
they're comfortable with.

== How it all fits together

image::architecture-simple.svg[Simple architecture overview,800,,align="center"]

The short version: a small computer (a Raspberry Pi) running Home Assistant becomes
the new "brain" of the villa, replacing the TIS Control panel. It talks to Zigbee
devices (lights, switches, sensors) directly over a local Zigbee radio, and talks to
the villa's own VRF air-conditioning system over the local network. None of this
requires an internet connection to work day-to-day - internet access is only
involved if you choose to enable optional remote control from your phone while away
from home. See the link:docs/guide-technical.adoc#_architecture[technical guide's
architecture section] for the full diagram and every component involved.

== Getting help / community

This is a community-support effort, not a commercial product or a supported service.

* Start with the two guides above.
* If you get stuck, reach out to the neighbour(s) who've already done this rather
  than experimenting alone on shared community systems.
* If you find an error in these docs or improve on the setup, please contribute
  fixes back (via a pull request, or by passing changes to whoever maintains this
  repository) so the next neighbour benefits too.
