= Phase 4: TIS Control
:toc: macro
:toclevels: 2

Phase 4 villas shipped with *TIS Control* as the built-in home automation
system. This is the phase where the first successful Home Assistant conversion
was done, so it's the best-documented path in this repository.

toc::[]

== What Phase 4 villas have

[cols="1,2", options="header"]
|===
| Built-in hardware | Notes

| TIS Control panel
| The proprietary "brain". Left in place, unpowered/idle after conversion -
  nothing is damaged, and the change is reversible.

| TIS light switches
| **Native Zigbee devices.** Re-paired to your own coordinator - reused at zero
  cost.

| Motion sensors
| **Native Zigbee devices.** Re-paired the same way.

| TIS VRF AC controller + indoor units
| One dedicated controller and AC unit per villa (not shared). Controlled from
  Home Assistant via the
  https://github.com/linusali/hass-tis-vrf-ac[hass-tis-vrf-ac] custom
  integration over the LAN.

| RS485 bus devices (additional motion sensors, water & power metering)
| Not yet integrated - see the
  link:guide-technical.adoc#_roadmap[roadmap] in the technical guide.
|===
